# EDS223-HW1
## Environmental Injustice Patterns Across Maryland's Counties

### Purpose
The purpose of this repository is to create maps depicting air quality across Maryland's counties and how they overlap with counties in which people of color reside.

### What's in the repo?
This repository contains a Quarto file to create three different maps: the air toxics cancer risk (per 1 million people), the diesel particulate matter count (µg/m^3), and the percentage of people, all aggregated at a county-level. This repository also houses the EJ Screen data, but it is hidden in the .gitignore file. For further information on the data and how to access it, see Data section below. The file structure in this repository is as follows:

```
EDS223-HW1
│   README.md
│   ej_screen.qmd
|   ej_screen.pdf
│   Rmd/Proj files    
└───.gitignore
     └───data
            └───ejscreen
```

### Data
The necessary data is from [EPA EJScreen]('https://www.epa.gov/ejscreen') website. This source is no longer available, but can be found on an archived version of the website [here]('https://pedp-ejscreen.azurewebsites.net/).
