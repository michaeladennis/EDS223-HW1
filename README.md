# EDS223-HW1
## Environmental Injustice Patterns Across Maryland's Counties

### Purpose
The purpose of this repository is to create maps depicting air quality across Maryland's counties and how they overlap with counties in which people of color reside.

### What's in the repo?
This repository contains a .qmd file to create three different maps: the air toxics cancer risk (per 1 million people), the diesel particulate matter count (µg/m^3), and the percentage of people, all aggregated at a county-level.
